# 📚 Aprendendo C++

Repositório dedicado aos meus estudos e à prática da linguagem **C++**, reunindo exemplos, exercícios e experimentos desenvolvidos durante minha jornada de aprendizado em programação.

O objetivo é consolidar os fundamentos da linguagem, desenvolver o raciocínio lógico e explorar gradualmente conceitos mais avançados por meio da prática.

## 🎯 Objetivos

- Aprender e consolidar os fundamentos da linguagem C++.
- Desenvolver lógica de programação e resolução de problemas.
- Praticar estruturas de controle e repetição.
- Compreender estruturas de dados e manipulação de memória.
- Explorar os conceitos de Programação Orientada a Objetos (POO).
- Registrar minha evolução e manter meus estudos organizados.

## 📖 Conteúdos estudados

O repositório está organizado em diretórios e arquivos individuais, cada um dedicado a determinado conceito da linguagem.

| Conteúdo | Conceitos abordados |
|---|---|
| Variáveis e operadores | Declaração de variáveis, operadores aritméticos, lógicos e relacionais |
| Estruturas condicionais | Tomada de decisões e controle de fluxo |
| Estruturas de repetição | `for`, `while` e controle de loops |
| Funções | Criação, parâmetros, argumentos e sobrecarga |
| Recursividade | Funções recursivas |
| Arrays e matrizes | Armazenamento e manipulação de dados |
| Vetores | Utilização de `vector` |
| Listas e estruturas de dados | `stack` e `queue` |
| Ponteiros | Manipulação de endereços de memória |
| Struct | Criação e organização de estruturas personalizadas |
| POO | Introdução à Programação Orientada a Objetos |

## 🚀 Como executar os programas

Para executar os exemplos, é necessário ter um compilador C++ instalado.

### 1. Clone o repositório

```bash
git clone https://github.com/kalebe-Pereira/Aprendendo-Cpp.git
```

### 2. Entre no diretório

```bash
cd Aprendendo-Cpp
```

### 3. Compile um arquivo

Utilizando o G++:

```bash
g++ arquivo.cpp -o programa
```

### 4. Execute o programa

No Linux:

```bash
./programa
```

No Windows:

```bash
programa.exe
```

**Exemplo:**

```bash
g++ funcoes.cpp -o funcoes
./funcoes
```

Cada arquivo `.cpp` representa um exemplo independente, portanto, a compilação deve ser realizada individualmente, conforme o exercício desejado.
